# ApkStart (TR / EN Fork)

Bu proje [RoutineMiku/apkstart](https://github.com/RoutineMiku/apkstart) reposunun forklanmış halidir.

- **Diller:** Yalnızca **Türkçe (`tr`)** ve **İngilizce (`en`)** dil desteği içerir, gereksiz diller kaldırılmıştır.
- **Özellik:** Windows üzerinde Android APK dosyalarını çift tıklamayla kurup bağımsız pencerede çalıştırmayı sağlar.

---

### English

This repository is a fork of [RoutineMiku/apkstart](https://github.com/RoutineMiku/apkstart).

- **Languages:** Exclusively supports **Turkish (`tr`)** and **English (`en`)**; other locales removed.
- **Feature:** Installs and runs Android APK files on Windows with standalone windows and desktop shortcuts.

## Komutlar / Commands

```bash
# Bağımlılıklar / Install dependencies
npm install

# Başlat / Start
npm start

# Testler / Run tests
npm test
```
